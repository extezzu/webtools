How to check SSL certificate expiry for many domains

An expired certificate takes a site down for every visitor, and it usually happens on a domain nobody watches: an old landing page, a client site, a staging host. Here's how to check dozens or thousands of domains at once.

One domain: the command line

echo | openssl s_client -servername example.com -connect example.com:443 2>/dev/null | openssl x509 -noout -enddate

This prints notAfter=, the expiry date. In a browser, click the padlock → certificate details.

A list of domains: a small script

while read d; do
  end=$(echo | openssl s_client -servername "$d" -connect "$d:443" 2>/dev/null | openssl x509 -noout -enddate | cut -d= -f2)
  echo "$d,$end"
done < domains.txt > expiry.csv

Works, but you need to run it yourself, handle timeouts, and remember to run it again next month.
